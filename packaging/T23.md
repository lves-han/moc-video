### 外部原始证据格式

将目标证据完整返回项目的 `evidence/releases/T23-clean-macos/`；入口为 `observations.json`。它记录人类实际操作和原始观测，没有预填 PASS 样例。顶层字段：

| 字段 | 内容 |
| --- | --- |
| manifest_sha256, source, protected | 本次不可变 manifest 的 SHA 与其中源码/保护摘要 |
| target, macos | macos-arm64、目标真实系统版本 |
| clean_system_method | fresh-macos-install / restored-clean-snapshot / separate-clean-mac / dedicated-test-vm |
| human_observer | 实际观察者标识 |
| security_settings_changed, quarantine_removed, security_exceptions | 实际布尔值与例外列表；本验收要求 false、false、[] |
| security_commands | 两条系统安全查询，逐条含 argv、exit、evidence（原输出文件的材料 ID） |
| artifacts | 材料 ID → {path, sha256}；path 为项目相对路径且须位于当前 clean-macos 目录 |
| recording | 首播录制的材料 ID |
| phases | 下列八个阶段，逐条含实际 utc 与非空 evidence 材料 ID 列表 |

阶段按表顺序发生，时间晚于本次构建；各原始文件均非空且 SHA 匹配。

| 阶段 | 实际字段和原材料 |
| --- | --- |
| baseline | app_exists=false、data_exists=false；干净安装前屏幕、目录清单/清洁来源 |
| installed | destination、file_tree（目标安装文件树 JSON 的材料 ID） |
| initialized | window_visible、ready、settings_file（目标设置原文材料 ID） |
| first_play | samples[{elapsed_seconds,position_seconds}]、moving_picture、audio_audible、errors；无录制时引用 screen_samples 和用户原话 audio_confirmation |
| upgrade_before | ready、file_tree、settings_file、history_db；对应实际 build 1 |
| upgrade_after | window_visible、ready、file_tree、settings_file、history_db；对应实际 build 2 |
| uninstalled | app_exists、data_exists、settings_file、history_db；数据原文与升级后保持一致 |
| data_deleted | app_exists、data_exists、explicit_test_data_deletion、remaining_owned_processes；对应显式测试数据清理 |

file_tree JSON 使用实际安装文件相对 app 路径作为键，值为 {sha256, bytes, mode}，mode 为 POSIX 权限十进制整数（如可执行文件 0755 对应 493）。与 release.tree 同一测量定义，可通过目标系统的文件 SHA/stat 输出形成；保留实际测量命令。evidence 列表须包含本阶段引用的 file_tree/settings_file/history_db 材料。

A1 重新读取安全日志、文件树 JSON、设置原文和真实 SQLite；报告内预填 settings/history/app_files/output 值均由原材料重读值覆盖。录制会由宿主 ffprobe 解码计数，要求至少5秒、有视频帧和音轨，再由 ffmpeg 解码 PCM 核对非零音频能量，测量日志省略相机位置及设备元数据。画面、UI 进度和声音的来源关联由实际观察者及原录制共同记录，属于人类执行的干净机器验收。缺材料、空材料、静音/缺音轨、同包伪升级、丢数据或安全例外都会失败。

macos-x86_64、windows-x86_64、linux-x11、linux-wayland 均为 NOT RUN（ADR-005/006，缺目标环境）；当前复现入口与迁移前提记录在 A1 的 deferred 项。
