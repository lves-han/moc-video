# T24 当前构建独立验收

执行入口只经原 `scripts/run.py`，`{python}` 为当前项目虚拟环境解释器。开发源码先保存为固定 `WIP T0.35:` 提交；源码摘要必须与该提交一致。测试运行期间保持源码稳定。

1. `run.py t24-endurance -- {python} -B tests/acceptance/t24.py --suite endurance --report evidence/acceptance/T24-endurance.json --junit evidence/acceptance/T24-endurance.xml`
2. 独立只读审阅者检查同批原始证据与固定提交，保存原报告到 `docs/reviews/T24/round-<N>.md`，随 `docs:` 提交。
3. `run.py A1 -- {python} -B tests/acceptance/t24.py --suite all --report evidence/acceptance/T24-all.json --junit evidence/acceptance/T24-all.xml`
4. A1 全过后直接执行 `scripts/verify.py all`，随后依原规则记录、勾选、done、完成提交和独立巡检。

前置实跑复用原正式 App、Video.js、Rust Host、网关及原生窗口助手，重新构建生产安装包和测试构建。两种 H264/AAC 1080p30 格式各实际连续播放至少 600 秒，保存约每 5 秒的帧、媒体与官方 UI 进度、前台状态、输入审计及 CPU/RSS/GPU 样本；共 5 次不同进程身份的完整窗口开关。MP4 同时观察 WebAudio；原生 HLS 通过 ScreenCaptureKit 的自有应用 PID 过滤采集实际 PCM，原始音频、逐 buffer PTS/offset 和正常停录结果均保存。系统录屏权限缺失时明确失败，用户声音确认沿 ADR-058 归 T0.36/A2。

同一固定测试构建还执行公开 Stremio 中文元数据→Rust 来源匹配/确认→实际播放/切集/历史，以及受控来源的正式 UI→SQLite 写入失败恢复、跨季身份、重启续播、缓存和关闭排空。当前来源支持及媒体可用性从各候选的脱敏 records 独立复算，保留网络失败与访问控制状态。安装包执行现有 ZIP/DMG、载荷、许可和实际签名检查。干净系统安装生命周期由 T0.36/A2 承接。

前置输出 `evidence/acceptance/T24-endurance-current.json` 指向唯一批次 manifest。原 payload 日志打印 `T24_MANIFEST_SHA256:<SHA256>`，原收据的 `log_hash` 绑定该日志。最终 A1 重读每个文件、源码/保护摘要/generation、固定构建文件树、原收据/日志、全部长播和生命周期断言、PCM、来源、产品/历史及安装包证据；历史成功报告保留其原源码身份。

独立报告应先给出逐项审查理由、实际执行命令/结果、缺陷与修复复测证据，再附一个 JSON 代码块。JSON 字段如下，数值与文件摘要均取实际本批证据：

- `commit`、`source`、`protected`、`generation`：manifest 的固定受验提交和基线。
- `manifest`：当前 manifest 的 `{path, sha256, bytes}`。
- `files`：manifest.files 中每个 path→sha256，再加入 manifest 自身、原 receipt、receipt.log 以及 release manifest 的 path→sha256。审阅者复核原文件后记录摘要。
- `obligations`：准确包含 U01..U09、G0-Core、G1..G5；各项 `{result, evidence, reason}`，证据写具体文件/代码/实际命令及观察。通过时 result 为 PASS，U07说明首版结构，G5说明 ADR-058 的阶段分工和实际签名状态。
- `unresolved_blockers`：当前未解决阻断列表。
- `personal_use_only: true`、`public_distribution_authorized: false`：沿 ADR-048。

末行必须为 `ACCEPTANCE-VERDICT: CLEAR` 或 `ACCEPTANCE-VERDICT: BLOCKING`。入口只读 N 数值最大的轮次；缺报告、未提交、缺绑定、旧源码、证据缺失/改写或阻断结论均失败。作者修复源码后重新固定提交、执行前置实跑并由独立审阅者复审。

macOS arm64 为当前必需目标；其余桌面平台、移动运行及干净系统生命周期按既有 ADR 如实标记 NOT RUN。资源后端为 process-watchdog 的 4096MiB 进程树 RSS 采样、构建并行 2、测试线程 1；采样允许瞬时超限。
