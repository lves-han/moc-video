# 映象视频 任务路线

状态：DRAFT。尚无可执行任务卡，驱动器会拒绝启动开发会话。

用 PROMPT-PLAN.md 根据真实目标编制任务；单卡格式见 TASK-TEMPLATE.md。
每卡只交付一个内聚行为；优先1–3项验收，最多6项。卡依赖须出现在前面。
验收 JSON 数组是唯一机器权威定义，命令使用 argv 数组，不由模型的最终消息判断完成。

## 需求覆盖

根据完整产品文档逐项填写，原文已有稳定 ID 时沿用，否则分配稳定 ID 并保留原文位置。每项要求指向卡与准确验收，每张卡的“需求”字段反向对应；批准排除注明真实授权来源，待决定项不可冒充覆盖。

| 需求 ID / 原文位置 | 产品要求及准确条件 | 卡号 / 验收 ID | 批准排除或待决定及来源 |
| --- | --- | --- | --- |

独立文档审查原始报告保存在 `evidence/doc-review/<round>/report.md`，PROGRESS.md 引用报告和受审版本/摘要。`task.py check` 仅检查格式；当前文档取得独立 CLEAR 且用户明确要求开发后，才进入开发阶段。
