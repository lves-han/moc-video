## DNS 固定公共解析检查（2026-11-11 14:34 CST）

结论：业务来源及媒体的公共 HTTP 路径固定使用 1.1.1.1:53 / 8.8.8.8:53 UDP，字体下载存在遗漏，应用整体尚未满足“所有 DNS 均走两个指定解析器”。本机业务来源失败的直接原因已确认是收到非公网地址，并触发既有 unsafe_target 校验。

- 静态入口审计：MacCMS、Stremio、图片、媒体、字幕、HLS 子资源及重定向共用 maccms::Http。其 Hickory ResolverConfig 只包含两个指定 DNS，禁用 hosts、无系统 DNS 失败回退；HTTP 禁用环境代理并通过 resolve_to_addrs 绑定解析结果，核验实际 peer。IP 字面量直接校验，无 DNS；WebView 访问的媒体网关为 127.0.0.1 字面量。
- 字体例外：src/ui/fonts.ts 向 loadFontBytes 传入 WebView fetch，远程 raw.githubusercontent.com 的解析由 WebView 网络栈处理，应用没有指定 DNS。后续缓存命中不请求网络。此项为 OPEN；本次检查未改动字体网络路径。
